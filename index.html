🟢 Гайд: Запуск сайту адвоката Караканової на GitHub Pages

1️⃣ Підготовка репозиторію

Переконайся, що у репозиторії є файли:

/index.html
/style.css
/photo.jpg

Якщо є пробіли у назвах файлів (наприклад index. html) → перейменуй на index.html.

2️⃣ Увімкнення GitHub Pages

  • Відкрий репозиторій на GitHub.
  • Перейди в Settings → Pages.
  • У розділі Source обери:
    • Branch: main
    • Folder: /root
  • Натисни Save.
Після цього GitHub автоматично згенерує URL для твого сайту.

3️⃣ Отримання посилання на сайт

URL буде приблизно таким:

https://nataliotor.github.io/karakanova/

Відкривши його, ти побачиш головну сторінку (index.html).

4️⃣ Перевірка роботи

  • Відкрий URL у браузері → сайт має відображатися.
  • При змінах у index.html або style.css:
    1. Зроби коміт і пуш на GitHub
    2. Сторінка автоматично оновиться

5️⃣ Поради по стилю та контактам

Для контактів краще використовувати посилання:
